# Fitzeno Club Website

> A fitness club website with classes, coaching, journal, shop and enquiries.

## What it does

- Club, class and coaching pages
- Journal and product catalogue
- Private admin for content and enquiry follow-up
- Responsive design, search-friendly routes and metadata

## Technology

PHP 8.2, MySQL, Apache, JavaScript

## Local setup

1. Create an empty MySQL database.
2. Set local database details in `config.php`.
3. Open the site in WAMP; run `install.php` to create the admin account.

## Database and sample data

`app/schema.php` creates the schema and fictional starter content on local setup.

Only schema and fictional starter data are intended for this public repository. Live customer, patient, order and enquiry records are never part of this snapshot.

## Publication note

This repository is a source snapshot. It does not include deployment credentials, live database records, customer uploads or server backups. Create fresh secrets and review the application before production use.
